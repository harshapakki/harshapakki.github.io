Two jobs, one engineer

I started as a product engineer shipping features inside a team, and now I am the engineer a customer gets handed. The two need different instincts and I use both every week.

As an SDE 2018 – 2026

  • Ship inside a team. Feature work through enterprise code review, with versioned releases other teams depend on.
  • Own the quality bar. 68 tests on a mobile app I authored alone, 111 on a platform tool, plus PR audits and incident write-ups.
  • Build the paved road. Dev containers, release pipelines to an artifact registry, and browser-reachable VMs that killed multi-day environment setup.
  • Modernise what exists. ETL off on-premises SQL Server onto Spark with managed hosting, and high availability that holds under failover tests.

As an FDE 2026 – now

  • Learn the domain first. Sit with the people doing the work, model what they actually do, then write code against that.
  • Be the whole team. Requirements, build, auth, CI/CD, containers, monitoring, and the 2 a.m. question, all mine.
  • Make legacy usable. Wrap a decades-old ERP in an API so people who never saw a green screen can self-serve.
  • Leave it runnable. Runbooks, status pages and one-click paths so the customer's own staff keep going without me.
